# Проверки HDT 1.58.9

Установлена сборка `1.58.9.9009` из публичного коммита `d63bb80af46ff61cc37d3917aa760133172b4b12`. Исходный патч — `../hdt-wine-functional-v1.58.9.patch`. Конфликты с новой логикой рейтинга разрешены с сохранением полного списка сессии, `Db` для выбранного режима и подписок Tier7.

`result.json` содержит хэши пакета, официального exe, локальной сборки, установленного exe после исправления прозрачности, архива и манифеста. Все 69 официальных DLL сохранены. Добавлена `System.Resources.Extensions.dll`; главный PDB получен вместе с локальной сборкой.

`RunRegressionTests.cs` запускает существующие тесты HDT через reflection. В тестовом каталоге exe заменён тем же файлом, который установлен. `regression-tests.log` подтверждает 15 успешных тестов истории игр, Wine-кнопок и рейтинга solo/duos. Два upstream теста проверяют выбор между рейтингом последней игры и более свежим рейтингом клиента.

Патч прошёл `git apply --check` на чистом дереве коммита выпуска и `git diff --check` в исходном worktree. Guard проверен в изолированном каталоге до установки; все маркеры приняты. Трекер запущен в рабочем UMU/GE-Proton11-7 prefix, журнал подтвердил версию 1.58.9.9009 и .NET Framework 528049. Hearthstone на момент проверки был закрыт, поэтому работу overlay в матче эта проверка не покрывает.

Архив содержит 174 файла; после распаковки все хэши манифеста проверены. Пользовательские данные и токены в архив не включены. Для сборки использовать порядок из раздела «Примечания по сборке» в `../README.md`, официальный full-пакет 1.58.9 и Localization `d589e572fb71dea3638f5d8aee65411014003265`. Локальные журналы и скрипты сборки находятся в `$HOME/.cache/hdt-build/v1.58.9/`.
